# Vietnam Crossing

A small standalone first-person road-crossing prototype built with Vite, React, React Three Fiber, Three.js, and Rapier.

## Run locally

```bash
pnpm install
pnpm dev
```

Open the printed local URL in a desktop browser. Click to start, then use `WASD` to move, `Shift` to run, and the mouse to look. `Esc` releases pointer lock.

## Build

```bash
pnpm build
pnpm preview
```

## Vercel

Use `pnpm build` as the build command and `dist` as the output directory. The game is a client-side static Vite app and does not require serverless functions or environment variables.
